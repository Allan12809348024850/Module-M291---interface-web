# Prompts images — Lêkê Sneakers

Un prompt par paire de `data.json`. Génère chaque image, puis enregistre-la avec le **nom de fichier indiqué** dans un dossier `images-brutes/` à la racine du projet. Je les convertirai en WebP et les mettrai dans `images/`.

## Réglages

- Format **carré 1:1** (1024 × 1024 au minimum).
- Garde **le même style pour toutes** : même fond, même angle, même lumière. C'est ce qui donne l'effet catalogue.
- Si l'outil écrit du texte ou un logo sur la chaussure, régénère : les marques sont fictives, il ne faut aucun logo réel (pas de virgule Nike, pas de 3 bandes, etc.).

## Style commun (déjà inclus dans chaque prompt)

```
Product photo of a single sneaker, side profile facing left, centered, on a plain warm off-white background (#EBE8E1), soft studio lighting, subtle shadow under the sole, clean e-commerce catalog style, no text, no logo, no brand marks, no people, square 1:1
```
